# 語詞闖關遊戲：午夜12點・消失的神奇魔法書

國小語詞學習的劇情闖關遊戲。6 個房間、36 道語詞咒語、線索本與推理機關。

- 遊戲（直接按「推開古堡大門」＝預設設定的單人冒險）：https://andice0107.github.io/word-quest/
- 冒險篇章（遊戲前設定）：https://andice0107.github.io/word-quest/adventure.html
  - 抽題數、破關後是否再挑戰（重新抽題／抽過不再抽，全部抽完才是終極破關）
  - 每題作答時限（可設定秒數）、過關總時間計時
  - 單人冒險或多人闖關（最多 30 人）
  - 多人：商人出現機率（預設 60%）與交易時間（預設 60 秒）、精靈出現機率（預設 30%）、每幾關用一次魔法卡（預設 5 關）與每人使用時間（預設 30 秒）
- 多人闖關教師大螢幕：host.html（由冒險篇章進入），學生掃 QR code 開 play.html 加入
- 老師換題目：https://andice0107.github.io/word-quest/teacher.html（下載 Excel 題本 → 修改 → 上傳 → 套用或產生分享連結）

多人連線透過免費公開的 MQTT 中繼伺服器（broker.emqx.io，備用 broker.hivemq.com），不需要帳號；
勇者名字由系統隨機給，學生只能在 30 秒內加上數字學號；只傳送系統名字、學號、分數與作答。網址加上 `?local=1` 可在同一台電腦用多個分頁測試。

插畫與音效來自作者在 Padlet Arcade Wildcard 製作的原版遊戲。

## 題型與出題（2026-11 更新）

- 出題會隨機抽題、亂序；選擇題的選項也會打亂。單人模式題目留在原房間（機關要靠該房間的線索），房間內順序打亂；多人模式全部混合後分房。
- 題本「作答方式」欄：選擇、是非、填充（自動對答案，`|` 分隔多個正確答案）、造句／打字作答（老師批改）、寫國字、寫注音、改錯字、造詞、手寫作答（手寫板，老師批改）。
- 手寫板直接沿用「師生同步作答」工具（live-class-quiz）的 `js/ink.js` 與楷書字型，不另做一套。
- 手寫、打字題一律由老師批改：多人模式在老師端批改 ✔／✘ 後才公布；單人模式由老師按「老師批改」按鈕（遊戲中或結局頁）批改。田字格題（寫國字、寫注音、改錯字、造詞）一字一格、一字 60 分，每個字分開打 ✓／✗；手寫作答整題 100 分；造句、打字作答由老師從 50～200 分（7 個級距）點選。所有題目都要按「送出答案」才算，送出前可以改。
- 多人模式作答中，老師可開全畫面「📺 全班作答監控」（學生邊寫邊同步，預設遮住，可全開／全關、點一下開關單人）；學生端每題都有「🙈 遮住我的答案」。
- 強制作答時限：寫國字、寫注音 60 秒；造詞、改錯字、手寫作答 100 秒；造句、打字作答 180 秒（不受冒險篇章的每題秒數影響）。時間到會自動交出已寫的內容。
- 換題本頁可下載 `docs/給AI的題本設計提示詞.md` 和國語示範題本 `samples/demo-guoyu-handwriting.xlsx`。
